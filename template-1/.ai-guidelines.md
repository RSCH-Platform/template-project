# AI Agent Guidelines

This document contains strict instructions for AI agents modifying or adding features to this project. 
When asked to create new features or pages, you **MUST** adhere to the following rules to ensure consistency with the existing codebase:

## 1. Architecture: Layered Approach
- **Strict Layering**: Use a Thin Controller -> Service -> Model + Observer architecture.
- **Thin Controllers**: Controllers should only handle HTTP requests, validate input, and return responses. Business logic belongs in Services.
- **Models and Observers**: Keep Models focused on data structure and relationships. Use Observers for side effects (e.g., sending emails, updating related counts).

## 2. Backend Querying
- **Spatie QueryBuilder**: Always use `Spatie\QueryBuilder` for handling filtering, sorting, and including relationships in backend queries. Do not manually write complex filtering logic in the controllers or services.

## 3. Data Transformation
- **JsonResource**: Always wrap response data using Laravel's `JsonResource`. Never return raw Eloquent collections or models directly from the controller.

## 4. Performance: Deferred Loading
- **Inertia::defer**: Use `Inertia::defer()` to lazily load heavy data or metrics. This ensures the initial page load remains fast.

## 5. Frontend Interactivity
- **No Full Page Reloads**: Avoid full page reloads in React.
- **Use Axios for UI Updates**: For interactive, "Livewire-like" UI updates (e.g., toggling a status, quick inline edits), use `axios` for API calls instead of Inertia's `router.post` or `router.delete`.
- **Inertia Router Usage**: Only use `router.post/put/delete` when the action requires a full page transition or complex form submission that results in navigation.

## 6. Reusable Components
- **Existing Components**: Before creating new UI components, verify if existing ones can be used or extended. 
- You **MUST** use the following existing components where applicable:
  - `Modal.jsx` for any modal dialogs.
  - `SearchableSelect.jsx` for dropdowns with search functionality.
  - `Table.jsx` for displaying tabular data.
